# Masterclass 4 – Claude Code voor ondernemers (geen programmeerkennis nodig)

**Na deze les:** je weet waarom Claude Code meer kan dan een chatvenster en gebruikt het voor gewone bedrijfstaken.

## Wat is anders dan de chat?

Claude Code werkt **in een map op je computer**. Het kan bestanden lezen en schrijven, rekenen met echte code en dingen opslaan. Dus:

- "Analyseer `verkopen-2025.csv`" → Claude rekent het echt uit, in plaats van te schatten.
- "Maak 12 offertes op basis van deze lijst" → 12 bestanden in een map.
- Je bedrijfsprofiel blijft bewaard tussen sessies.

## Installeren

Volg de actuele instructies op code.claude.com/docs. Daarna in je bedrijfsmap: `claude`. Ook beschikbaar als desktop-app en op claude.ai/code.

## Basisbegrippen

| Begrip | Wat het is |
|---|---|
| Map / projectmap | Waar Claude werkt en bestanden bewaart |
| `CLAUDE.md` | Instructies die Claude bij elke sessie leest |
| Skill | Een opgeslagen werkwijze (zoals de specialisten van Business OS) |
| `/commando` | Start een skill of functie, bv. `/business-os:os` |
| Plugin | Een pakket skills – Business OS is er één |
| Toestemming | Claude vraagt voordat het iets wijzigt of uitvoert; lees mee |

## Praktische tips

- **Sleep bestanden** in de map en verwijs ernaar: "lees `prijslijst.pdf`".
- **Vraag om bestanden**, niet alleen tekst: "zet dit in een Excel" of "maak hier een Word-document van".
- **Begin een nieuwe sessie** voor een nieuw onderwerp; het profiel neemt de context mee.
- **Controleer** wat Claude wil uitvoeren als het om verwijderen of versturen gaat.

## Veilig werken

- Geen wachtwoorden of API-sleutels in chat of bestanden.
- Klantgegevens alleen als het nodig is, en anonimiseer waar het kan.

## Opdracht

Zet een export (verkopen, bezoekers of ads) in je map en vraag `/business-os:data` om de drie belangrijkste inzichten.
